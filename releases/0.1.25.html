Volt 0.1.25

Two credential bugs that made a working account look broken.

codex login mints a refresh token alongside an access token valid for
days. OpenAI revokes the refresh token issued by the previous
codex login on a machine, so a second login -- even for an unrelated
account -- kills the first one's token. Volt only refreshes within five
minutes of expiry, so an imported credential sat on that revocable login
token for its whole lifetime and died the next time the user signed in to
another account. Save & Test now forces one refresh, moving Volt onto a
descendant token that a later login leaves alone. The exchange is best
effort, so access-token-only setups and a flaky refresh endpoint still
import successfully.

Separately, the usage request treated 401 and 403 identically. A 403 from
the ChatGPT backend is routinely bot protection or a blocked network path,
but it surfaced as "OpenAI rejected the saved credentials", sending users
to re-import a perfectly valid token. 403 now maps to a plain server error
and keeps its refresh-and-retry, while only a 401 reports rejected
credentials.
